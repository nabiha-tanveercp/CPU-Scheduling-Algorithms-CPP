##CPU Scheduling Algorithms Simulator in C++

A C++ implementation of fundamental CPU Scheduling Algorithms developed from scratch to understand how modern operating systems manage process execution.

This project implements multiple scheduling techniques without using external libraries or STL containers, focusing on algorithm design, process management, and scheduling logic.

##Implemented Algorithms
First Come First Serve (FCFS)
Shortest Job First (SJF - Non Preemptive)
Shortest Remaining Time First (SRTF - Preemptive)
Round Robin (RR)

##Each algorithm calculates:

Completion Time
Turnaround Time
Waiting Time
Features
Dynamic memory allocation
Process scheduling simulation
Ready Queue implementation for Round Robin
Bubble Sort based process ordering
Turnaround Time calculation

##Why I Built This Project

I am an Electrical Engineering student with a strong interest in software development, embedded systems, operating systems, and computer architecture.

While this project began as part of my academic learning, I wanted to challenge myself by implementing every scheduling algorithm from scratch instead of relying on existing implementations.

Throughout this project, I learned how operating systems schedule processes, manage CPU time, and balance efficiency with fairness. Some algorithms, especially Round Robin, required multiple redesigns before I fully understood the execution flow and ready queue management. Rather than giving up, I kept improving the logic until I was able to build a working implementation.

This project has significantly improved my problem-solving skills, strengthened my understanding of C++, and given me practical insight into one of the core topics of Operating Systems.

It also marks another important milestone toward my long-term goal of becoming an engineer who can work confidently at the intersection of hardware and software, particularly in embedded systems, robotics, automotive software, computer architecture, and aerospace technologies.
